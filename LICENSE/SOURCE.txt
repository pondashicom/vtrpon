VTR-PON2 2.6.5 SOURCE INFORMATION

VTR-PON2 Corresponding Source
-----------------------------

Repository:
https://github.com/pondashicom/vtrpon

Exact release tag:
v2.6.5

Browsable source:
https://github.com/pondashicom/vtrpon/tree/v2.6.5

Source archive:
https://github.com/pondashicom/vtrpon/archive/refs/tags/v2.6.5.zip

The source tree includes package.json, package-lock.json, build configuration,
JavaScript/HTML/CSS sources, tests, and the scripts needed to build the
distributed application. The standard release scripts refuse to build unless:

1. the worktree is clean;
2. the local v2.6.5 tag points to the build commit;
3. the published origin v2.6.5 tag points to the same commit; and
4. origin is https://github.com/pondashicom/vtrpon.git.

The source must remain available for as long as the object code is distributed.
The release download page must provide clear access to this source next to the
binary download.

Third-party Corresponding Source
--------------------------------

The Windows and macOS distributions also contain platform-specific prebuilt
FFmpeg/ffprobe binaries.
Upstream sources for the fixed binary versions are:

- FFmpeg 6.1.1:
  https://ffmpeg.org/releases/ffmpeg-6.1.1.tar.xz
- FFmpeg 4.0.2:
  https://ffmpeg.org/releases/ffmpeg-4.0.2.tar.xz

Package wrapper sources and exact npm versions are identified in
THIRD-PARTY-NOTICES.txt and NPM-DEPENDENCIES-LOCK.json.
